- Provider 统一继承 `ChangeNotifier`，通过 `notifyListeners()` 在状态变更后通知 UI，并使用 `context.watch<T>()` / `context.read<T>()` 订阅或获取实例。
- 数据层采用单例模式（如 `DatabaseHelper.instance`），通过私有构造函数 `_init` 与静态字段缓存 `Database?` 实现懒加载。
- 异步操作遵循「设置 loading → notify → 执行 → 清除 loading → notify」四步模式，确保 UI 能反映中间状态。
- Feature 页面按目录组织（`features/<feature>/<page>.dart`），跨 feature 引用通过相对路径 `../../providers/...` 访问共享 Provider。
- 数据库操作统一通过 `DatabaseHelper` 的命名参数方法封装，SQL 建表语句以多行字符串字面量内联定义，避免 ORM 引入。
