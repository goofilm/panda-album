- 所有头文件使用传统 `#ifndef ... #define ... #endif` 形式的 include guard，命名格式为 `<FILE>_H_`。
- Win32 窗口扩展通过继承 `Win32Window` 并重写虚函数 `OnCreate`、`OnDestroy`、`MessageHandler` 来实现自定义逻辑。
- CMake 中通过 `apply_standard_settings` 宏统一设置 C++17、警告级别 `/W4 /WX`、异常处理 `/EHsc` 以及 `_HAS_EXCEPTIONS=0`。
- 资源与清单文件集中放在 `runner/resources/` 下，并通过 `Runner.rc` + `resource.h` 以资源 ID 形式引用图标等资源。
