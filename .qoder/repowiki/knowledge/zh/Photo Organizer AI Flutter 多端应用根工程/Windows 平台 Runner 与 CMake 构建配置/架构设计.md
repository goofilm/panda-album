该模块是 Flutter Windows 应用的 native runner，采用两层结构：
- `flutter/` 子目录由 Flutter 工具生成并管理（ephemeral、generated_plugin_registrant、CMakeLists.txt），负责引入 flutter_windows.dll、CPP wrapper（core_implementations.cc、standard_codec.cc、flutter_engine.cc、flutter_view_controller.cc）以及插件注册。
- `runner/` 子目录为应用入口：`main.cpp` 通过 `wWinMain` 初始化 COM、构造 `DartProject`、创建 `FlutterWindow` 并运行 Win32 消息循环；`win32_window.h/.cpp` 提供 DPI 感知、主题同步、窗口生命周期管理的基类；`flutter_window.h/.cpp` 继承自 `Win32Window` 并持有 `FlutterViewController` 来承载 Flutter 视图；`utils.h/.cpp` 提供命令行参数解析等辅助功能；`Runner.rc`、`resource.h`、`app_icon.ico`、`runner.exe.manifest` 定义资源与清单。
- 顶层 `CMakeLists.txt` 定义项目属性（C++17、Unicode、Debug/Profile/Release 三配置）、调用 `flutter/CMakeLists.txt` 和 `runner/CMakeLists.txt`，并通过 `install()` 将 DLL、AOT 库、ICU 数据和 flutter_assets 复制到可执行文件同级目录，使 VS 可直接运行。
依赖方向：`main.cpp` → `FlutterWindow` → `Win32Window` → Win32 API；Flutter 引擎通过 `flutter/` 下的 generated 代码桥接。
